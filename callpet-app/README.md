# 콜펫 케어 (MVP)

반려동물 일상 케어 기능 안에서 **콜펫(긴급수혈 매칭)** 을 가장 눈에 띄게 보여주는 앱의 MVP입니다.
기획서의 로드맵 1단계(MVP)와 2단계 일부(케어 리포트·예약·케어 콘텐츠·포인트 교환)를 구현했습니다.

## 포함된 기능

| 영역 | 기능 |
| --- | --- |
| 보호자 앱 (`/`) | 가입·로그인, 반려동물 프로필, 동물병원수첩(병원 기록), 일상 기록(산책·식사·물), 병원 공지, 알림, 포인트·배지 |
| 콜펫 | 헌혈 등록(동의·자격 기준 안내), 긴급 요청 알림, 수락/거절, 완료 후 포인트·배지 |
| 2차 기능 | 케어 리포트(병원 기록을 쉬운 문장으로 정리), 병원 예약(요청→병원 확정·거절→알림), 케어 콘텐츠와 7일 챌린지, 포인트 교환(시연용 목록) |
| 병원 관리 (`/hospital`) | 가입 신청→관리자 승인, 환자 연결(병원 코드), 진료·접종 기록, 혈액형 확정, 공지, 긴급 수혈 요청·매칭 현황·완료 확정 |

## 실행

Node.js 22.13 이상이 필요하고, 외부 패키지는 없습니다(SQLite는 내장 `node:sqlite`).

```bash
cd callpet-app
ADMIN_KEY=원하는-관리자-키 npm start   # http://localhost:3000
npm test
```

- `ADMIN_KEY`: 병원 승인 API(`/api/admin/*`)용 키입니다. 비워 두면 승인 API가 꺼집니다.
- `DB_PATH`(기본 `callpet.db`), `PORT`(기본 3000)
- 병원 승인: `curl -X POST -H "x-admin-key: $ADMIN_KEY" localhost:3000/api/admin/hospitals/<id>/approve`
  (대기 목록은 `GET /api/admin/hospitals?status=pending`)

## 시연용 데이터

```bash
DB_PATH=demo.db npm run seed -- --reset      # 병원 2곳·보호자 3명·반려동물 4마리, 열린 긴급 요청 1건
DB_PATH=demo.db ADMIN_KEY=원하는-키 npm start
```

모든 시연 계정의 비밀번호는 `demo-pass-1234`입니다(공개된 값이므로 운영 DB에는 쓰지 마세요).
`01090000001`(보호자 김하늘, 보리)로 로그인하면 긴급 요청 알림이 대기 중이고, 병원은 `0212340001`로 로그인합니다.
시연 흐름: 보호자 수락 → 병원 매칭 현황에서 확인 → 헌혈 완료 확정 → 보호자 포인트·배지 확인.

## 설계 원칙

- **혈액형은 병원이 확정한 값만 매칭에 씁니다.** 보호자가 입력한 값은 참고용입니다.
- **연락처는 수락 전에 공개하지 않습니다.** 병원은 보호자 이름·연락처를, 보호자는 병원 연락처·주소를 수락 후에만 봅니다.
- **헌혈 자격 기준은 참고용입니다.** `lib/eligibility.js`의 수치(나이·체중·간격)는 일반적인 범위를 기본값으로 둔 것이라 **출시 전에 수의사 검토로 확정해야 합니다.** 최종 판단은 수의사가 합니다.
- 포인트는 현금성 보상이 아니라 감사 표시(포인트·배지)입니다.
- 외부 서비스 없이 동작하며, 화면은 인라인 스크립트·스타일 없이 CSP를 적용합니다.

## 아직 없는 것 (로드맵 2·3차)

- 푸시 알림: 지금은 앱을 열어 둘 때 15초마다 확인합니다. 출시 전 FCM/APNs 연동이 필요합니다.
- 케어 리포트는 **규칙 기반 요약**이며 AI 모델을 쓰지 않습니다(`lib/report.js`). 실제 진료 음성 변환·LLM 요약은 별도 작업입니다.
- 케어 콘텐츠와 포인트 교환 목록은 시연용 정적 데이터입니다(`lib/content.js`). 실제 운영에는 수의사 감수와 제휴사 연동이 필요합니다.
- EMR 연동 어댑터
- 병원 주소→좌표 변환(지금은 가입 시 위도·경도를 직접 입력하거나 현재 위치를 씁니다)
- 개인정보 처리방침·이용약관 화면, 관리자 화면, 비밀번호 재설정, 요청 속도 제한

## 구조

```
server.js          HTTP 서버(정적 파일 + JSON API)
lib/db.js          SQLite 스키마
lib/api.js         라우트·권한·비즈니스 규칙
lib/eligibility.js 헌혈 자격 참고 기준
lib/matching.js    혈액형 호환·거리·후보 선정
lib/report.js      케어 리포트(규칙 기반)
lib/content.js     케어 콘텐츠·챌린지·교환 목록(시연용)
scripts/seed.js    시연용 데이터
public/            보호자 앱(guardian.js), 병원 화면(hospital.js)
test/              규칙·API 흐름 테스트
```
