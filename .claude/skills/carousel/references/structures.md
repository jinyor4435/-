# 골격 변형과 플랫폼 기준

SKILL.md의 기본 골격(훅 → 문제 → 고통 → 기존방식 부정 → 하지만 → 해법 → 회수 → CTA)이 기본값이다. 주제가 안 맞을 때만 아래로 바꾼다. **어느 골격을 쓰든 답은 절반 지점 이전에 주지 않는다.**

## 1. 리스트형 — "N가지"

정보성 주제, 저장을 노릴 때.

1. 훅 — 숫자를 걸되 항목은 감춘다 ("놓치면 손해인 3가지")
2. 이걸 모르면 뭘 잃는지 (여기가 없으면 그냥 목록이 된다)
3~N. 항목 하나당 한 장 — 제목 한 줄 + 설명 두 줄 + 예시 한 줄
N+1. 요약 — 세 항목을 한 화면에 다시 배치
N+2. CTA

함정: 항목을 나열만 하면 2장에서 다 이해되고 끝난다. **각 항목 끝에 다음 항목을 궁금하게 만드는 한 줄**을 남긴다.

## 2. 비포·애프터형

변화를 보여줄 수 있을 때 가장 세다.

1. 훅 — 결과만 슬쩍 ("같은 내용, 다른 결과")
2. 비포 — 예전 방식 그대로 (구체적일수록 좋다)
3. 그래서 뭐가 안 됐는지
4. 무엇을 바꿨는지 **한 가지만**
5. 애프터
6. 왜 그게 먹혔는지 (원리)
7. 지금 바로 적용하는 법
8. CTA

## 3. 오해 깨기형

이미 다들 안다고 믿는 주제일 때.

1. 훅 — 통념을 그대로 적는다 ("열심히 쓰면 읽힌다?")
2. 다들 이렇게 알고 있다
3. 그래서 다들 이렇게 한다
4. **그런데 결과는 반대다**
5. 진짜 이유
6~7. 그래서 어떻게 해야 하나
8. CTA

## 4. 스토리형

경험·실패담이 있을 때. 지어낸 경험은 쓰지 않는다.

1. 훅 — 장면 하나 ("300개를 썼고, 아무도 안 봤습니다")
2. 상황
3. 무너진 순간
4. 시도한 것들 — 다 실패
5. **하지만 여기서 하나가 달랐다**
6. 발견
7. 지금의 결과 (실제 수치만, 없으면 【확인】)
8. 당신에게 적용하면
9. CTA

## 플랫폼별 기준

| | 슬라이드 | 비율 | 장당 글자 | 특징 |
|---|---|---|---|---|
| 인스타 캐러셀 | 8~10장 | 4:5 (세로가 화면을 더 먹는다) | 40~70자 | 첫 장이 탐색 탭에서 잘릴 수 있으니 문구를 중앙에 |
| 스레드 | 5~7개 체인 | 텍스트 | 100자 내외 | 첫 글이 훅. 이미지 없이 문장만으로 끊어야 하므로 미완형 훅이 유리 |
| 링크드인 | 9~12장 | 4:5 또는 1:1 | 50~90자 | 조금 더 논리적·업무적 어휘 허용. 다만 전문용어 남발은 여전히 이탈 요인 |

## 슬라이드 수 판단

- 메시지가 하나인데 12장이 나오면 늘어진 것이다 — 중복 장을 지운다
- 8장 미만인데 각 장이 꽉 차 있으면 쪼갤 곳이 있다는 뜻이다
- 마지막 두 장(회수 + CTA)은 어떤 골격에서도 빼지 않는다
