# Canva로 디자인까지 만들기

카피가 확정된 뒤에만 시작한다. **디자인은 카피를 바꾸지 못한다** — 이 순서가 뒤집히면 Canva의 AI가 훅을 세 줄짜리 설명문으로 다시 써놓고, 그걸 되돌리느라 시간을 더 쓴다.

실제로 10장을 만들어보고 정리한 순서다. 각 단계에서 무엇이 어긋나는지까지 적었다.

## 전체 흐름

```
카피 확정 → 개요 승인(사용자) → 프레젠테이션 생성 → 1080×1350 리사이즈
  → 페이지별 정리(생성 문구를 원본 카피로 덮어쓰기) → 커밋 → PNG 내보내기
```

## 1단계 — 개요를 올리고 사용자 승인을 받는다

`request-outline-review`에 확정된 카피를 그대로 넣는다. 슬라이드 제목에는 그 장의 **첫 줄**을, description에는 나머지 줄과 디자인 메모를 하이픈 목록으로 적는다.

Canva 규칙상 사용자가 위젯에서 승인해야 다음 단계로 갈 수 있다. 승인 없이 `generate-design-structured`를 부르면 안 된다.

`length`는 10장이면 `balanced`를 쓴다(기본값 `short`는 1~5장이라 카드뉴스에 모자란다).

## 2단계 — 생성하고 규격을 바꾼다

`generate-design-structured`(`design_type: presentation`)는 후보를 3~4개 준다. **페이지 수가 카피 장수와 정확히 맞는 후보**를 고른다. 나머지 후보 URL은 사용자에게 남겨준다 — 스타일이 마음에 안 들면 다시 고를 수 있다.

`create-design-from-candidate` → `resize-design`(`custom`, 1080×1350)으로 4:5를 만든다. 리사이즈는 **새 디자인 ID**를 만들므로, 이후 작업은 반드시 새 ID로 한다.

인스타 캐러셀은 `instagram_post` 타입이 1080×1350이지만 한 장짜리다. 여러 장은 이 프레젠테이션 경로가 유일하다.

## 3단계 — 페이지마다 정리한다 (여기가 본 작업)

`read-design`에 `open_transaction: true`로 열어 페이지별 `locator_id`를 받는다. 한 번에 5장씩 읽으면 응답이 관리 가능한 크기로 온다.

생성 결과에는 세 가지 문제가 **매번** 있다. 그대로 두면 카드뉴스가 아니라 발표 슬라이드가 된다.

1. **AI 일러스트에 깨진 글자가 들어간다.** 한글 자리에 아랍어처럼 보이는 문자가 박힌 이미지가 나온다. 이미지 요소(`fill.media.type === "image"`)는 **전부 지운다.** 확대해 확인하느라 시간 쓰지 말고 지우는 게 빠르다.
2. **본문이 설명문으로 다시 쓰였다.** "이 말은 프리랜서가 견적서를 다시 열게 만드는 중요한 신호입니다…" 같은 문장이 들어온다. `replace_text`로 원본 카피를 덮어쓴다.
3. **레이아웃이 작은 제목 + 각주다.** 카드뉴스는 큰 타이포가 화면을 채워야 한다.

페이지당 이 순서로 한 번에 보낸다.

```
delete_element   (이미지, 배경과 같은 색의 빈 채움 도형)
replace_text     (원본 카피 — 줄바꿈 \n 그대로 살린다)
resize_element   (width 920)
format_text      (제목 96 bold / 본문 46, color, line_height)
position_element (제목 top 430, 본문 top 790, left 80)
```

**`position_element`는 반드시 마지막에 둔다.** `format_text`가 텍스트 높이를 다시 계산하면서 위치를 끌어당긴다 — 먼저 배치하면 본문이 제목에 달라붙는다.

불릿 목록으로 생성된 본문은 `format_text`에 `list_level: 0`, `list_marker: "none"`을 같이 넣어야 점이 사라진다.

## 4단계 — 세 장은 손을 더 댄다

- **1장(훅)**: 배경을 어둡게 두고 문구만 흰색으로 크게(110 내외). 훅 뒤에 깔린 밝은 판은 지운다. 하단 계정 문구는 `width`를 920으로 넓히지 않으면 두 글자가 다음 줄로 넘어간다.
- **전환 장("하지만")**: 페이지 배경색은 직접 못 바꾼다. 대신 페이지 전체 크기의 도형을 넣고 `layer_element`로 뒤로 보낸다. 삽입과 레이어 이동은 **다른 호출로 나눠야** 한다 — 새 도형의 `locator_id`는 삽입 결과에서만 나온다. 그 다음 글자를 흰색으로 바꾼다.
- **회수 장**: 두 줄이 그룹으로 묶여 크기가 서로 다르게 나온다. `ungroup_elements` 후 두 줄을 같은 크기로 맞추고, 사이에 얇은 도형(height 4, opacity 0.35)을 넣어 가로선을 만든다.

## 5단계 — 넘침을 눈으로 확인한다

편집 응답에 페이지 썸네일이 온다. **매번 본다.** 한글은 폭 계산이 어긋나기 쉽다.

경험칙: 폭 920 기준으로 **글자 크기 × 글자 수 × 0.95 < 920**이어야 한 줄에 들어간다. 96px이면 9~10자, 64px이면 14자쯤이다. 넘치면 크기를 줄이지 말고 **줄바꿈을 넣는 쪽**을 먼저 고려한다 — 카드뉴스는 큰 글씨가 생명이다.

## 6단계 — 커밋하고 내보낸다

`edit-design`에 `finalize: "commit"`, `operations: []`로 확정한다(편집과 커밋은 같은 호출에 못 넣는다). `get-export-formats`로 지원 형식을 확인한 뒤 `export-design`으로 PNG를 뽑아 페이지별 링크를 사용자에게 준다.

## 사용자에게 남길 것

- 편집 링크(사용자가 직접 고칠 수 있게)와 PNG 링크
- 손대지 않은 부분: 해법 장들의 1/2/3 표시 같은 디테일은 Canva 앱에서 직접 넣는 게 빠르다
- 다른 스타일 후보 URL

## 이 경로를 쓰지 않는 게 나을 때

한 장짜리(스레드 이미지, 단일 게시물)는 `generate-design`에 `instagram_post`로 바로 만든다. 개요 승인이 필요 없다.

브랜드 키트가 있으면 `list-brand-kits`로 확인하고 생성 단계에서 `brand_kit_id`를 넘긴다. 다만 색·폰트가 카드뉴스에 필요한 대비를 못 낼 수 있으니, 훅 장의 가독성은 따로 확인한다.
