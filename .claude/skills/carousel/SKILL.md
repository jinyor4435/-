# 카드뉴스(캐러셀) 작성

캐러셀은 글이 아니라 **넘기는 동작을 설계하는 일**이다. 읽는 사람은 앉아서 읽지 않는다. 엄지로 스크롤하다 0.5초 멈추고, 넘길지 말지 결정한다. 그래서 잘 쓴 문장이 아니라 **다음 장이 궁금해지는 문장**이 이긴다.

이 스킬은 세 가지 룰 위에서 동작한다. 룰을 지키는 것이 목적이 아니라, 세 룰이 각각 캐러셀이 죽는 세 가지 지점(안 멈춤 / 중간 이탈 / 이해 실패)을 막기 때문에 지킨다.

## 시작하기 전에 확인할 것

다음 네 가지가 없으면 캐러셀이 뭉개진다. 대화에서 이미 알 수 있으면 묻지 말고 진행하고, 비어 있는 것만 짧게 한 번 묻는다.

1. **주제 한 줄** — 무엇에 대한 이야기인가
2. **타깃** — 누가 읽는가 (초보인가 실무자인가에 따라 단어가 완전히 달라진다)
3. **딱 하나의 메시지** — 다 읽고 나서 남길 문장 한 개. 두 개면 캐러셀 두 개로 쪼갠다
4. **플랫폼** — 인스타 캐러셀(4:5, 8~10장) / 스레드(텍스트 체인) / 링크드인(9~12장). 슬라이드 수와 문장 길이가 달라진다

없는 숫자·사례·후기는 **절대 지어내지 않는다.** 근거가 필요한 자리는 `【확인: 실제 수치 넣기】`로 남기고 사용자에게 알린다. 지어낸 숫자 하나가 계정 신뢰를 통째로 깎는다.

## Rule 1 — 첫 장은 한 문장

첫 장에 3~4줄짜리 설명을 적는 순간 이미 졌다. 첫 장(hook)의 역할은 정보 전달이 아니라 **안 넘기고는 못 배기게 만드는 것** 하나뿐이다.

- **한 문장, 두 줄 이내, 20자 내외.** 25자를 넘어가면 잘라낼 곳이 있다는 뜻이다.
- 배경 설명·인사·자기소개는 전부 뺀다. 탐색 탭에서 스치듯 본 사람이 0.5초 안에 이해해야 한다.
- 마침표는 대개 빼는 게 낫다. 문장이 닫히면 궁금증도 같이 닫힌다.
- **호기심의 방향을 정한다.** 훅은 "이거 나 얘기네"(공감) 또는 "어? 왜?"(반전) 둘 중 하나로 걸린다. 둘 다 노리면 둘 다 놓친다.

훅 유형과 실제 문장 패턴은 `references/hook-patterns.md`에 있다. 훅을 쓸 때는 이 파일을 읽고, **최소 5개를 뽑아 놓고 하나를 고른다.** 첫 번째로 떠오른 훅은 대부분 설명문이다.

```
✗ 카드뉴스를 만들 때 첫 장이 중요한 이유와 사람들이
   자주 하는 실수 3가지를 정리해봤습니다
✓ 첫 장에서 이미 진 겁니다
```

## Rule 2 — 핵심을 바로 주지 마라

훅은 잘 걸어놓고 2번 장에서 정답부터 주면, 머무를 이유가 사라진다. 스와이프가 끝나고, 끝까지 보는 사람이 줄고, 노출도 같이 떨어진다.

그래서 **답은 뒤로 미루고, 그 전까지 긴장을 쌓는다.** 기본 골격은 이렇다.

| 구간 | 역할 | 감정 |
|---|---|---|
| 1장 | 훅 — 한 문장 | 어? |
| 2장 | 문제 제시 — 지금 뭐가 안 되고 있는지 | 맞아, 나도 |
| 3장 | 고통 증폭 — 그래서 실제로 뭘 잃는지 | 아 짜증나 |
| 4장 | 기존 방식 부정 — 다들 이렇게 한다, 그런데 | 어 나도 그렇게 했는데 |
| 5장 | **"하지만"** — 긴장 최고점, 여기서 답을 예고만 한다 | 그래서 뭔데 |
| 6~8장 | 해법 — 한 장에 하나씩 | 오케이 |
| 9장 | 회수 — 훅의 문장을 다시 꺼내 닫는다 | 아 그래서 그 말이구나 |
| 10장 | CTA — 하나만 | 저장 |

**5장의 "하지만"이 이 구조의 심장이다.** "기존 방식이 맞는 것 같지만, 통하지 않는다" — 이 한 줄이 사람들을 계속 넘기게 만든다. 4장에서 독자가 자기 방식을 스스로 확인하게 만든 다음, 5장에서 그걸 뒤집기 때문에 힘이 생긴다. 순서를 바꾸면 그냥 잔소리가 된다.

지켜야 할 것 두 가지.

- **한 장에 메시지 하나.** 두 개를 넣고 싶으면 장을 쪼갠다. 슬라이드는 공짜다.
- **모든 장은 다음 장으로 넘어갈 이유를 남긴다.** 문장이 완결되면 손가락도 멈춘다. 3장 끝에 "그런데 진짜 문제는 여기가 아니다" 같은 미끼를 남긴다.

주제에 따라 골격은 바꿔도 된다(리스트형, 비포·애프터형, 오해 깨기형 — `references/structures.md`). 바꾸더라도 **답을 절반 지점 이전에 주지 않는다**는 원칙은 유지한다.

## Rule 3 — 단순함이 이긴다

똑똑해 보이는 단어를 쓸 필요가 없다. 중요한 건 이해되는 것이다. 어려운 단어는 감탄이 아니라 혼란을 만들고, 혼란스러운 사람은 반응하지 않는다.

- 전문용어는 **읽는 사람의 말로 번역한다.** 리텐션 → 끝까지 보는 사람, 도달률 → 몇 명한테 보이는지, 인게이지먼트 → 반응, 퍼널 → 사는 데까지 오는 길.
- 한 문장 25자, 한 장 3줄을 넘기지 않는다. 넘으면 대개 문장 두 개가 붙어 있는 것이다.
- 수식어를 빼고 동사를 살린다. "효율적인 관리가 가능합니다" → "덜 걸립니다".
- 리듬을 만든다. 짧은 문장 · 짧은 문장 · 조금 긴 문장. 같은 길이가 이어지면 눈이 미끄러진다.

### 다 쓰고 나서 스스로에게 묻는다

1. **중학생이 읽어도 한 번에 이해되나?** 두 번 읽어야 하면 문장을 쪼갠다.
2. **소리 내 읽었을 때 걸리는 곳이 있나?** 걸리는 자리가 곧 이탈 지점이다.
3. **더 쉬운 단어로 바꿀 수 있나?** 바꿀 수 있으면 바꾼다. 예외는 없다.
4. **한 장에 메시지가 두 개인 장이 있나?** 있으면 쪼갠다.
5. **첫 장만 보고 다음 장을 넘기고 싶은가?** 아니라면 훅부터 다시 쓴다.

## 출력 형식

작성이 끝나면 이 형식 그대로 낸다. 디자이너나 편집 앱에 그대로 넣을 수 있어야 하므로, 슬라이드 텍스트에 설명을 섞지 않는다.

```
## 1 · 훅
{한 문장}

## 2 · 문제
{제목 한 줄}
{본문 1~3줄}

... (마지막 장까지)

---

### 캡션
{첫 두 줄로 승부. 그다음 본문, 마지막에 CTA 한 개}

#해시태그 #10개내외

### 디자인 메모
- 강조할 단어: ...
- 장별 이미지/색 힌트: ...
```

완성된 형태 그대로의 예시는 `references/example-output.md`에 있다. 형식이 헷갈리면 그 파일을 그대로 본뜬다.

캡션은 캐러셀의 요약이 아니라 **못 다한 이야기 한 조각**이다. 요약을 적으면 넘길 이유가 사라진다.

마지막 장 CTA는 **하나만** 쓴다. 저장·공유·팔로우·댓글을 나열하면 아무것도 안 한다. 저장을 원하면 "저장해두고 다음 글 쓸 때 꺼내 보세요"처럼 **저장할 이유**를 준다.

## 검수

초안을 파일로 저장한 뒤 검사 스크립트를 돌린다. 사람이 눈으로 세면 반드시 놓치는 것들(글자 수, 문장 수, 전환 위치, 전문용어)을 대신 잡아준다.

```bash
python3 .claude/skills/carousel/scripts/check_carousel.py 초안.md
```

고치기 요청을 받았을 때는 **사용자가 붙여넣은 초안을 그대로 넣어도 된다.** `[1장]`, `## 슬라이드 1`, `**1/9**`, `3장:` 표기를 모두 읽는다. 형식을 바꿔가며 손보느라 시간을 쓰지 않는다.

경고가 나오면 **기계적으로 자르지 말고 문장을 다시 쓴다.** 글자 수 초과는 대개 "문장이 길다"가 아니라 "한 장에 메시지가 두 개다"라는 신호다.

스크립트가 잡지 못하는 것 — 훅이 실제로 궁금한지, "하지만" 전환이 힘이 있는지, 답을 너무 빨리 줬는지 — 는 위 다섯 질문으로 직접 점검한다.

## 자주 죽는 패턴

- **1장에 설명을 적는다** — 가장 흔하고 가장 치명적이다. 설명은 2장부터다.
- **2장에서 결론을 말한다** — 남은 8장을 아무도 안 본다.
- **"~할 수 있습니다" 나열** — 정보는 있는데 감정이 없다. 문제와 고통을 먼저 세운다.
- **한 장에 항목 5개** — 5장으로 쪼갠다.
- **마지막에 CTA 3개** — 하나만.
- **전문용어로 권위 세우기** — 아는 사람만 읽고 끝난다.
- **훅과 결론이 따로 논다** — 마지막 장에서 훅의 단어를 그대로 회수하면 완성도가 올라간다.

## 디자인까지 만들 때

카피가 끝난 뒤 Canva로 실제 디자인을 만들 수 있다. **순서가 중요하다 — 카피를 먼저 확정하고, 디자인은 그 카피를 담기만 한다.** Canva의 생성 AI는 넘겨준 문구를 자기 식으로 다시 쓰기 때문에, 생성한 뒤 원본 카피로 덮어쓰는 단계가 반드시 들어간다.

`references/canva-design.md`에 실제로 10장을 만들어보고 정리한 순서가 있다. 디자인을 요청받으면 그 파일을 읽고 따른다.

## 자동화가 필요할 때

같은 룰로 주제만 넣으면 카피와 카드 이미지를 한 번에 뽑는 웹 앱이 이 저장소에 있다 — `carousel.html`.
반복해서 여러 건을 만들거나 사용자가 직접 돌려보고 싶어 하면 그 쪽을 안내한다.
프롬프트는 `js/carousel-prompt.js`, 카드 그림은 `js/carousel-render.js`에 있고,
**룰 문구를 이 스킬에서 고치면 `js/carousel-prompt.js`도 같이 고쳐야 한다.**
