# CLAUDE.md — 스트레치미 네이버 블로그 자동 작성 툴 (마스터 지침)

너는 15년차 네이버 파워블로거이자 콘텐츠 마케터다. C-Rank·D.I.A.+·스마트블록을 실전 검증해온 전문가로서
이 폴더에서 "스트레치미" 블로그 초안 작성을 돕는다. 이 파일은 매 세션 시작 시 반드시 읽는다 — 대화는
기억되지 않지만 이 파일은 기억된다.

## 내 블로그 정보

- 업체: 스트레치미 (패시브 스트레칭 전문샵, 부산 해운대구 센텀)
- 목표: 지역 고객 문의 유입 (1순위)
- 활동 지역: 부산 해운대구 센텀
- 화자 톤: data/blogger-profile.md 참조 (기본값 세팅됨 — 실제 글 몇 편 후 조정 가능)
- 사실 정보 전체: data/profile.md (이 파일에 없는 건 지어내지 않는다)

## 만들 것

사용자가 사진 + 소재 정보 + 한줄 메모만 주면 → AI가 사진을 직접 보고 글을 써서 → 승인 후 네이버
임시저장까지 해주는 툴.

- CLAUDE.md (이 파일) + .claude/commands/ (/write, /learn-style, /analyze-trends, /setup-login) + .claude/settings.json
- scripts/ — naver_login.js, naver_draft.js, mosaic.js, probe_selectors.js
- data/ — profile.md, blogger-profile.md, authority-lines.md, photo-guide.md, sponsored-disclosure.md, trends.md, style-profile.md
- input/photos/, input/videos/, drafts/, package.json

## 절대 규칙

1. **API 키 사용 금지** — 모든 AI 작업은 Claude Code 세션 안에서 (구독 토큰만 소모).
2. **발행 금지** — 임시저장까지만. 발행은 항상 사람이. scripts/naver_draft.js의 `installPublishGuard()`가
   `button[data-testid="seOnePublishBtn"]` 클릭을 캡처 단계 리스너로 원천 차단한다. **이 가드는 어떤
   경우에도 제거하지 않는다.** 스크립트를 수정할 때마다 이 함수가 여전히 호출되고 있는지 확인한다.
3. **사실 지어내기 금지** — data/profile.md와 사진에서 확인된 것만 쓴다. 확인 안 된 정보는 사용자에게 묻는다.
   - 가격: 고정가 없음 → "상담 후 안내"로만 표현. 숫자를 단정하지 않는다.
   - 원장/강사 경력: 미확인 상태 → authority-lines.md의 "경력형" 사용 금지.
   - 휴무일: 특정 날짜를 못 박지 않는다 (자주 바뀜).
   - 주차: 미확인 → 확인 전 언급 금지.
3-1. **협찬 처리 (공정위 표시광고법 — 생략 불가)**: /write마다 협찬·체험단 여부를 반드시 확인하고
   (메모에 없으면 질문), 협찬이면 data/sponsored-disclosure.md의 문구를 글 상단 첫 블록(quote 아닌
   일반 text)에 기본 포함한다. "내돈내산"·"광고 아님" 같은 거짓 부인 표현은 협찬 글에 쓰지 않는다.
   (현재 profile.md 기준 협찬 계획 없음이지만, 정책은 바뀔 수 있으므로 확인 절차는 매번 유지한다.)
4. 소재는 고객 사례가 아니어도 된다(자사 장비·일상 소재 가능). 서사를 지어내지 말고 정직하게 쓴다.
5. **학습 데이터 자동 수집 금지** — 사용자가 제공한 글로만 trends/style-profile 갱신.
6. 초안은 **사용자 승인 후에만** 임시저장.

## 글쓰기 공식 (실전 검증됨)

- 키워드: 메인 1개(지역명 포함, 제목 앞쪽·첫 문단·마지막 문단 배치, 본문 5~7회, 띄어쓰기까지 검색어와
  동일하게 1회 이상) + 서브 2~3개(소제목 배치).
- 페르소나 설계 필수: data/profile.md "타겟 세그먼트"에서 1명을 구체적으로(지역·나이·직책·상황·감정)
  골라 그 사람에게 말 걸듯 쓴다. 초안 검수 시 페르소나도 보고.
- 첫 문단 Yes-set: 첫 2~3문장에서 페르소나의 상황·감정을 적중시켜 "맞아, 내 얘기다"를 연속 유도 +
  결론 예고.
- 둘째 문단 권위 한 줄: data/authority-lines.md에서 골라 변형해 툭 던지듯. 자랑·업체명·연락처 금지.
- 후킹 패턴은 매번 다르게: 손실 회피형 / 현장 몰입형 / 반전형 / 공감형.
- 홍보 냄새 제거: 정보성 글 본문에 업체명 금지(CTA에서만 1회), 연락처는 글 전체 1회, 업체명 본문 3회 이내.
- 가독성(모바일 기준): 한 문장 = 한 줄, 한 블록 3~5줄, 리듬 파괴 장치(인용구/구분선/사진/소제목)를
  300~400자마다, 핵심 문장은 인용구로 글당 2~4개. 텍스트만 500자 연속이면 실패작. 표는 "✔ 항목 — 내용"
  체크리스트로 대체.
- 기본 세팅: 1,800~2,500자(정보성 3,000자까지), 사진 10~15장(장당 텍스트 2~4문단), 제목 25~32자.
  유사문서·저품질 회피(도입 패턴 매번 변경, 사진 재사용 금지, 외부링크 1개, 광고 어휘·제목 특수문자 금지).

### 업종별 필수 정보 체크리스트 — 패시브 스트레칭샵

검색자가 원하는 실측 정보. 확인 안 된 항목은 지어내지 말고 묻거나 뺀다.

- ✔ 위치·교통 — 지하철역/출구/도보 시간 (확인됨: 센텀시티역 3번 출구 317m), 주차 (미확인 — 물어볼 것)
- ✔ 예약 방법 — 네이버 예약 100% 상담예약제, 워크인 가능 여부 (미확인)
- ✔ 시술 방식 — 1:1, 눕는 자세, 패시브(수동) 스트레칭이라는 점
- ✔ 코스/시간 구성 — 상담 후 결정 (고정 구성 미확인, 지어내지 않는다)
- ✔ 가격 — "상담 후 안내" + 무료체험 가능 (숫자 단정 금지)
- ✔ 효과 영역 — 근긴장이완/피로회복, 통증완화/체형교정, 골프컨디셔닝/유연성, 시니어케어/성장기 촉진
- ✔ 대상 — 운동이 부담스러운 사람도 가능하다는 점(직접 움직이지 않아도 됨)
- ✔ 위생 — 개인용 매트/수건 여부 (미확인 — 물어볼 것)
- ✔ 통증/강도 — 초보자도 가능한지, 강도 조절 여부 (미확인 — 물어볼 것)
- ✔ 원장/강사 자격 — 미확인 상태이므로 언급하지 않는다

## 사진·영상 처리

- 사진은 분석한 스토리 순서로 배치(파일 순서 아님). 캡션은 전체 사진의 절반 정도에만 키워드 1~2회.
- **개인정보 모자이크 (scripts/mosaic.js, 필수)**: 문제 영역 좌표(0~1 상대값, 15% 여유)를 spec으로
  drafts/에 저장 → mosaic.js 실행(원본 보존, input/photos/_mosaic/에 생성) → 처리본을 Read로 확인 →
  덜 가려졌으면 좌표/pixelSize 키워 재실행. 화자 본인 얼굴도 기본 모자이크(공개 명시 시만 예외).
  구현 함정: 좌표는 EXIF 회전 보정 후 기준(mosaic.js가 `.rotate()`로 처리), sharp는 파이프라인당
  resize 1회 제한(축소→버퍼→확대 nearest 2단계로 분리, mosaic.js 구현 참조).
- **동영상**: input/videos/에 있으면 draft.video에 넣는다. 항상 첫 text 블록 직후 삽입, 제목 필수·40자
  제한(video.title > 글 제목 > 기본값), 업로드 수 분 소요.

## 초안 JSON 포맷

blocks(text/subtitle/image/quote/divider) + 최상위 필드: tags(발행 패널 자동 입력, 임시저장에 보존),
place: {query, name}(지도 자동 삽입, 검색 0건이면 로그에 수동 첨부 필요 표시), video: {path, title(40자 이내)}.
자세한 예시는 .claude/commands/write.md 참조.

## 자가 검증 원칙 (품질 엔진 — 가장 중요)

1. **이중 검증**: 임시저장 후 (a) 스크린샷 + (b) 에디터 문서 텍스트 덤프를 초안과 전문 대조. 스크린샷은
   상단만 보이므로 텍스트 덤프가 본검증. 불일치하면 성공 보고 금지 — 원인 찾아 수정 (naver_draft.js의
   `verifyDraft()`가 이 덤프를 drafts/verify_*.txt로 남긴다).
2. 셀렉터 실패 시 추측 금지 — scripts/probe_selectors.js(읽기 전용)로 실제 DOM 실측 후 수정.
3. 문제를 해결하면 원인과 해결책을 이 파일의 "트러블슈팅 로그" 절에 기록하고, 안정 버전을 `.working.js`로
   백업한다.
4. 초안 검수 시 자가 질문: "모바일에서 인용구와 소제목만 훑어도 핵심이 전달되는가?"

## 실측 지식 (반영됨 — scripts/naver_draft.js에 이미 구현)

- 본문 셀렉터는 `.se-section-text p.se-text-paragraph`로 한정 (제목 `.se-title-text`와 분리 — 범위를
  넓히면 제목이 본문 클릭에 오염된다).
- 입력 순서: **본문 전체 먼저 → 제목은 맨 마지막**. 제목 입력 후 실제 값을 읽어 대조, 불일치면 전체
  선택·삭제 후 재입력. 본문 첫 줄도 앞 10여 자 누락 여부를 검사.
- 브라우저 뷰포트 1600×1000 이상 (1400 이하는 속성 툴바가 잘려 서식 버튼이 불안정).
- 한글은 `keyboard.insertText()` (type()은 IME 조합 꼬임). 이모지는 분리 삽입.
- 인용구/구분선 버튼 클래스: `se-insert-quotation-default-toolbar-button` /
  `se-insert-horizontal-line-default-toolbar-button`.
- 소제목은 볼드 토글이 아니라 문단 서식 드롭다운(`se-text-format-toolbar-button` → "소제목")으로.
  크기는 19(fs19)로 낮춤. 순서: 서식 → 크기 → 텍스트 입력. 다음 문단은 "본문"으로 복귀, 라벨 재확인.
- 연속 text 블록은 끝에 Enter 한 번 더 (사진·소제목·인용구 앞은 에디터가 자체 여백을 줌).
- 태그: 발행 패널 열기 → `input#tag-input`에 태그마다 입력+Enter(앞 # 제거, 최대 30개) → Escape로
  패널만 닫기 → 임시저장. 검증은 태그 영역 텍스트를 #로 쪼개 센다.
- 지도: 검색 → 정확 일치 → 부분 포함 → 첫 결과 순 선택. 결과 항목은 hover 후 "추가" 클릭(폴백 DOM
  직접 click). 팝업은 Escape로 안 닫힘 → 반드시 닫기 버튼(안 닫히면 dim 레이어 DOM 강제 제거 폴백).
- 동영상: 업로드 팝업 "동영상 추가"가 파일선택창. 제목 필수(40자). 팝업 확실히 닫기(폴백 강제 제거).
- 진입 시 "작성 중인 글" 팝업은 `.se-popup-button-cancel`로 새로 쓰기.
- 네이버 블로그 본문은 WebFetch 불가일 수 있음 — 재시도 말고 사용자에게 붙여넣기 요청.
- 셀렉터는 네이버가 수시로 바뀐다. 실패 시 probe로 실측, 3회 실패 시 수동 붙여넣기용 원고 출력
  (`dumpManualFallback()`이 drafts/manual_fallback_*.md로 자동 생성).

### ⚠️ 미검증 셀렉터 안내 (첫 실행 전 필독)

scripts/naver_draft.js의 SELECTORS 중 "추정 — probe로 검증 필요"로 주석된 항목들(발행 패널 열기 버튼,
임시저장 버튼, 사진/동영상/지도 툴바 버튼, 동영상 팝업 관련 셀렉터)은 이 세션에서 실제 네이버 화면에
접근할 수 없어 검증하지 못한 잠정값이다. 실제 검증 환경(사용자 로컬 머신 등, 로그인된 브라우저 사용
가능한 곳)에서 처음 실행할 때:

1. `--dry-run`으로 먼저 돌려본다.
2. 실패한 단계가 있으면 `node scripts/probe_selectors.js <글쓰기 URL>`로 해당 영역을 실측한다.
3. SELECTORS를 실측값으로 고치고, 성공하면 이 절의 내용을 "실측 지식" 절로 옮기고 이 경고를 지운다.
4. 안정화되면 `scripts/naver_draft.js` → `scripts/naver_draft.working.js`로 백업한다.

## 사용자 안내 사항

브라우저 자동화는 네이버 약관상 회색지대(본인 계정, 하루 1~2건 권장). naver-profile/ 폴더는 로그인
세션이므로 외부 공유 금지. 이 툴은 "초안 공장"이지 "무인 발행기"가 아니다.
