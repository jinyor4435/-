# /learn-style

학습 데이터 자동 수집은 절대 금지 — 사용자가 이 대화에 직접 붙여넣거나 파일로 준 글로만 갱신한다.

1. 사용자에게 참고할 글(본인이 쓴 과거 글, 또는 벤치마킹하고 싶은 글)을 붙여넣거나 파일 경로로 달라고 요청한다.
2. 받은 글에서 문장 길이, 어미 습관, 이모지/느낌표 사용 빈도, 후킹 패턴, 자기 지칭 방식을 분석한다.
3. data/blogger-profile.md의 기존 캐릭터와 충돌하는 부분이 있으면 사용자에게 확인한다 (임의로 덮어쓰지 않는다).
4. data/style-profile.md에 발견한 패턴을 정리해 기록한다. 언제, 어떤 글을 근거로 갱신했는지도 남긴다.
