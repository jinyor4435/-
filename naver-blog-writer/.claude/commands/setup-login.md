# /setup-login

1. 사용자에게 이 명령이 브라우저 창을 열고, 네이버 계정(jinyor2)으로 직접 로그인해야 한다고 안내한다.
2. `node scripts/naver_login.js` 를 실행한다.
3. 브라우저가 열리면 사용자가 직접 로그인을 완료한다 (비밀번호는 이 툴에 입력하지 않고 네이버 화면에만 입력).
4. 로그인 완료 후 터미널에서 Enter를 눌러 세션을 저장한다. 세션은 naver-profile/ 폴더(persistentContext 유저 데이터 디렉토리)에 남는다.
5. naver-profile/ 폴더는 로그인 세션이므로 절대 외부에 공유하거나 커밋하지 않는다 (.gitignore 확인).
6. 로그인 확인 실패 메시지가 뜨면 다시 실행해서 이어서 로그인해도 된다.
