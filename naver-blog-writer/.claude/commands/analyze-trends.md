# /analyze-trends

학습 데이터 자동 수집은 절대 금지 — 사용자가 직접 붙여넣거나 링크로 준 글/키워드/캡처만 반영한다. 임의로 웹을 긁어서 채우지 않는다.

1. 사용자에게 최근 본 경쟁 블로그 글, 인기 키워드, 검색 트렌드 캡처 등을 요청한다.
2. 받은 자료에서 도입부 패턴, 자주 쓰이는 서브 키워드, 사진 배치 방식 등을 정리한다.
3. data/trends.md에 날짜와 함께 기록한다 (언제, 무엇을 근거로 추가했는지 남긴다).
4. profile.md의 메인/서브 키워드 후보와 겹치거나 갱신이 필요하면 사용자에게 확인 후 반영한다.
