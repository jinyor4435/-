# 🏛️ 딥테크 정부지원사업 계획서 생성기

딥테크 아이템 발굴 → 사업 기획 → 사업계획서 작성 → 모의심사 → IR Deck까지,
정부지원사업 준비의 전 과정을 **심사위원 관점**으로 만들어 주는 웹 앱입니다.

**API 키가 필요 없습니다.** 앱이 각 단계에서 심사위원 페르소나와 도메인 지식이 내장된
프롬프트를 생성하고, 사용자는 그것을 Claude(claude.ai 등)에 붙여넣은 뒤 응답을 앱에
되붙입니다. 앱이 응답을 파싱해 저장하고 최종 문서(DOCX/PPTX/PDF/HWP 호환)로 조립합니다.

## 실행 방법

빌드가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```bash
# 그냥 열기
open index.html          # macOS
start index.html         # Windows

# 또는 로컬 서버로 (권장 — 클립보드 API가 더 안정적)
python3 -m http.server 8000
# → http://localhost:8000
```

모든 데이터는 브라우저 localStorage에만 저장됩니다 (서버 전송 없음).
「내보내기 → 프로젝트 백업」으로 JSON 백업/복원이 가능합니다.

## 파이프라인

| 단계 | 내용 | 결과물 |
|---|---|---|
| ⚙ 설정 | 사업 유형 선택(창업패키지 PSST / 딥테크 TIPS·R&D / 지자체 공모 / 공고문 기반 범용) + 팀 정보 | 목차·배점·심사 관점 확정 |
| 0. 공고문 분석 | **공고문 파일(HWP·HWPX·PDF·DOCX·PPTX)을 올리면** 브라우저 안에서 텍스트를 추출하고, **실제 제출 양식의 목차·배점·실격 조건**을 분석 | 공고 양식이 4단계 목차를 자동 대체 |
| 1. 아이템 발굴·재정의 | **신규 발굴**: 12개 딥테크 분야(국가전략기술 기반)에서 5개 생성 / **재정의**: 기존 사업의 비효율을 기술적 병목으로, 보유 데이터를 해자로 격상하는 딥테크 리프레이밍 | 아이템 카드 + 심사위원 매력도 |
| 2. 사업 기획 | PSST 구조로 기획 확정 — 시장·KPI·매출·BEP의 **단일 진실 공급원** (+[P11] PoC 개요) | [P1]~[P11] 기획서 |
| 3. PoC 검증 설계 | 가설 1개 → 환경·방법·비교군 → 지표(정의·단위·측정법·산출식) → 숫자 임계값(Go/No-Go) → Plan B | PoC 캔버스 (계획서 붙임 자동 첨부) |
| 4. 계획서 작성 | 배점 비례 지면 배분, 섹션별 개조식(□/○/-) 작성. 기획·PoC·기존 섹션 요지가 프롬프트에 포함되어 일관성 유지 | 섹션별 본문 + 미리보기 |
| 5. 모의심사 | 섹션별 채점, 감점 요인 전수 점검, 수치 불일치 검사, 【확인】 마커 목록, 대면평가 압박질문 4종 방어 시뮬레이션 | 심사 결과 + 수정 지시 3가지 |
| 6. IR Deck | 대면평가용 12장 이내 설계 (슬라이드당 메시지 1개, 발표 대본 포함) | 슬라이드 미리보기 |
| 📦 내보내기 | DOCX / PDF / PPTX / HWP 호환 / JSON 백업 | 제출용 파일 |

## 심사위원 관점이 어디에 들어있나

모든 프롬프트에 심사위원 페르소나와 함께 실제 감점 요인 체크리스트가 포함됩니다:

- 가정치를 실적처럼 서술 (가정치 표기 강제, 미확보 정보는 【확인】 마커)
- top-down 매출 추정 (지불 주체 기반 bottom-up 강제)
- 과도한 전환율, IP 뭉뚱그리기(권리자·출원번호·류 명시), 외주 개발 권리 귀속
- 규제를 리스크로만 서술 (정책 방향과 일치 시 "수혜자" 프레이밍)
- 요약-본문-Deck 간 수치 불일치, 페이지 제한 위반 등

4단계 모의심사는 같은 체크리스트로 문서 전체를 역방향 검증합니다.

## 산출물 형식

- **미리보기** — 제출본 형태로 전체 문서를 크게 확인하고 그 자리에서 인쇄까지. 4단계와 내보내기에서 열 수 있습니다.
- **한글 파일 (.hwpx)** — 한컴오피스 한글이 바로 여는 개방형 표준(OWPML). 열어서 `다른 이름으로 저장 → .hwp`로 바꾸면 제출용이 됩니다. 개조식 계층과 표를 유지합니다.
- **DOCX** — 맑은 고딕, 개조식 계층, 마크다운 표 → Word 표 변환 ([docx](https://github.com/dolanmiu/docx) 내장). 한글에서도 열립니다.
- **PPTX** — 16:9, 표지 + 슬라이드 + 발표자 노트(대본) ([PptxGenJS](https://github.com/gitbrent/PptxGenJS) 내장)
- **PDF** — 인쇄 대화상자 → "PDF로 저장". 새 창이 막힌 환경에서는 숨은 프레임으로 인쇄를 시도합니다.
- **한글에 붙여넣기** — 파일 없이, 열려 있는 한글 문서에 서식 그대로 붙여넣기

> `.hwpx` 생성은 ZIP·XML 구조와 자체 파서 왕복까지 검증했지만, 이 개발 환경에는 한컴오피스 한글이 없어
> **실제 한글에서 열리는지는 확인하지 못했습니다.** 열리지 않으면 DOCX를 받아 한글에서 여는 경로를 이용하세요.

## 공고문 파일 업로드

0단계에 공고문 파일을 끌어다 놓으면 텍스트를 뽑아 원문 칸에 쌓습니다. 여러 개를 한 번에 올릴 수 있고,
**파일은 브라우저 안에서만 처리되며 어디로도 전송되지 않습니다.**

| 형식 | 처리 방식 |
|---|---|
| **HWP** (한글 5.0) | OLE 복합문서를 직접 파싱 → 본문 스트림 압축 해제 → 문단 레코드 추출. 표·문단 구조 유지 |
| **HWPX** | ZIP+XML(OWPML) 파싱 |
| **PDF** | pdf.js로 텍스트 추출. **한국어 CMap을 내장**해 한글이 깨지지 않으며, 좌표 기반으로 표 구조를 복원 |
| **DOCX / PPTX** | ZIP+XML 파싱, 표는 `셀 \| 셀` 형태로 보존 |
| **확장자만 PDF인 스캔본** | 실제로는 ZIP(JPEG+OCR 텍스트)인 공공기관 배포본을 자동 판별해 OCR 텍스트 추출 |
| **TXT / MD** | UTF-8 우선, 깨지면 EUC-KR로 재시도 |

암호 걸린 HWP, 텍스트 레이어가 없는 스캔 PDF는 그 사실을 알려주고 대안을 안내합니다.

## 구조

```
index.html          앱 진입점 (빌드 없음, script 태그 로드)
css/style.css       스타일
js/programs.js      사업 유형별 목차·배점·페이지 배분, 딥테크 분야, 감점/고득점 체크리스트
js/prompts.js       단계별 프롬프트 빌더 + 관대한 JSON 응답 파서
js/hwpx.js          한글 문서(HWPX/OWPML) 생성기 — ZIP 작성기 포함
js/fileparse.js     공고문 파일 파서 (HWP·HWPX·PDF·DOCX·PPTX)
js/export.js        개조식 파서, DOCX/PPTX/PDF/HWP 내보내기
js/app.js           위저드 UI, localStorage 상태 관리
js/vendor/          내장 라이브러리 (docx, PptxGenJS, pdf.js, 한국어 CMap — 전부 오프라인 동작)
scripts/bundle.js   단일 HTML 번들러
dist/app-single.html  더블클릭으로 실행되는 독립 실행본
```

## 제출 전 주의사항

- 이 도구의 페이지 수는 근사치입니다. **실제 워드/한글에서 연 페이지 수**로 제한 준수를 확인하세요.
- 【확인】 마커(설립일, 특허번호 등 미확보 사실)는 제출 전 반드시 실제 값으로 채우세요. 허위 기재는 대부분의 공고에서 자격 박탈·지원금 회수 사유입니다.
- 공고문 요약과 실제 제출 양식(HWP)의 목차가 다른 경우가 많습니다. 0단계에 **양식 본문까지** 붙여넣으세요.
